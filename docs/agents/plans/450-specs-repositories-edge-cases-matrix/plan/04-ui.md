# ui.md rules

**`ui.md`:**

- **`#table`:**
  - muted source badges for a not-ok source (tooltip "<source> could not be refreshed") and for
    a `pending` one ("<source> has not been synced yet");
  - the `409` inline error row, "Fix the integration that sees this repository in
    Integrations.", linking to `#/account/integrations`.
- **`#source-errors`:**
  - the `not_found` banner, *GitHub handle "x" was not found on GitHub. Check it on your Account
    page.*, linking to `#/account/my-account`;
  - only integration sources show the `invalid_credentials` banner.
- **`#empty-state`:** the second empty state ("No repositories found. Check the sources above.")
  and the no-match message ("No repositories match your filters.").
- **`#edge-cases`:** replace the open marker with the ten UI rules from the issue:
  - an emptied page jumps to the last page;
  - no row updates while syncing;
  - Add state is kept by `githubId` across the reload;
  - an Added row stays under the "Not added" filter until reload;
  - a pruned row's `404`;
  - the handle never shows `invalid_credentials`;
  - banner dismissal per (source, status, `syncedAt`), in memory;
  - a deleted integration's badges go on reload;
  - the two empty states.

  Then a pointer to `edge-cases.md`.
- **Required tests:** one per new rule (the issue's UI list), plus the muted badge, the
  `not_found` banner and the `409` error.
