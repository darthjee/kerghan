# Add the nodemailer dependency

Add `nodemailer` as a runtime dependency and its types as a dev dependency, then regenerate the
lockfile inside the container.

- `nodemailer` → `dependencies` in `backend/package.json`. Pin with a caret range matching the
  style of the existing entries (current stable is `^6.9.x` — use the latest 6.x the registry
  resolves).
- `@types/nodemailer` → `devDependencies`, caret range (`^6.4.x`).
- Regenerate `backend/yarn.lock`: `docker-compose run --rm kerghan_tests yarn install`. Never
  run `yarn` on the host (`AGENTS.md`).
- No change to the `resolutions` block — none of nodemailer's transitive deps are listed there.
- Do **not** bump `backend/package.json`'s `version` — that is the release flow's job.
