# Add the deku-swarm dependency

Add `deku-swarm` as a runtime dependency of the backend, through `docker-compose` only (never `yarn`/`npm` on the host), so `package.json` and `yarn.lock` are updated by the container:

```bash
docker-compose run --rm kerghan_app yarn add deku-swarm
```

Pin an exact, released version (at least a couple of weeks old) rather than a floating range, and confirm it imports under the backend's ESM + `NodeNext` setup (the package is `"type": "module"`; relative imports in our code keep their `.js` extensions). Check whether it ships types; if not, add a minimal ambient declaration under `backend/src/types/` for the symbols used (`Job`, `JobFactory`, `JobRegistry`, `Worker`, `WorkerFactory`, `WorkersRegistry`, `Engine`).

## Files to Change
- `backend/package.json` — new `deku-swarm` dependency.
- `backend/yarn.lock` — regenerated by the container.
- `backend/src/types/deku-swarm.d.ts` — only if the package ships no types.
